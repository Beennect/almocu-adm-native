# Almocu State Patterns
## When to Use
- state management decisions
- new store creation
- theme/data state
## Key Stores
- stores/AuthStore.ts - authentication state
- stores/DataStore.ts - application data
- stores/ThemeStore.ts - theme/toggle state
- stores/ToastStore.ts - toast notifications
## Patterns
- zustand for global state
- stores as standalone modules
- typed stores with TypeScript
