# Agentes:

## SuperAgentes: É a camada superior, na qual é quem vai receber os prompts do usuário, eles não tocam no código, mas são mais sobre fluxos de desenvolvimento (não é que exista super agentes, seria um agente focados em resolver problemas espécificos), (é quem vai ter conhecimento do projeto todo)
- ProblemSolver (Deep Seek): Especializado em enteder e corrigir problemas de código
- Builder (Deep Seek): Para implementar novos recursos
- Discution (Deep Seek): Agente para poder debater e discutir sobre o ideias e implementações do projeto, ele vai ter conhecimento completo do projeto, eu vou perguntar para ele as coisas e ele vai me responder, vou dar ideias e ele vai falar se é viavel implementar. Ele não tem um fluxo, ele tem conhecimento do projeto, sobre o que está sendo feito, e pode enviar o Code Reviewer para olhar o código e executar comandos para comfirmar hipoteses

## Agentes: É a camada que vai receber ordem dos Superagentes, focado em tarefas especificas, eles não botam a mão na massa, mas delega os subagentes, poderia até dizer que eles estão mais para um fluxo de trabalho do que agentes, mas é bom deixar como agente para ficar especializado naquele fluxo
- ProblemIdentifier
- PropostSolution
- SolutionImplementation

## Subagentes: Realiza o trabalho braçal de colocar a mão no código e implementar os recursos, corrigir, documentar, etc... 
- Coder (local) (MiniMax): Especializado na linguagem daquele projeto, após cada alteração vai criar um documento markdown sobre cada alteração que foi feita, e o mótivo 
- Code Reviewer (Global) (MiniMax): Analisa o código a procura de erros de sintaxe, erros de lógica, duplicação desnecessária de código, ver se está sendo implementado as boas práticas, etc...
- Documenter (global) (Deepseek): Ele vê as alterações que foram feitas e atualiza a documentação que é o AGENTS.MD
- Tester (local) (Deepseek): Executa comandos para ver se o recurso ou a correção do bug foi implementada corretamente

# Fluxo de Trabalho
## Agentes (quando não definido subagente que vai realizar aquela atividade, é o próprio agente que vai realizar aquela atividade)
- ProblemIdentifier(problema a ser resolvido)
    1. Recebe o prompt compreendendo qual é o problema que o usuário está reclamando (se necessário pedir mais informações para ter mais detalhes e compreender melhor a dor do usuário)
	2. (Code Reviewer) Identifica o problema no código, pensar quais são os possiveis problemas, confirmando isso no código
	3. (Tester) após montar as hipoteses, se possivel realizar testes para confirmar as hipoteses com comandos ou execução de testes
	4. com isso decidir os problemas, e montar um arquivo markdown apresentando quais são as possiveis causas do problema

- PropostSolution(Recebe situações para implementações de recursos ou problemas a serem corrigidos)
	1. Monta as melhores soluções para aquele projeto seguindo padrões de projetos e boas práticas
	2. Apresenta para o usuário as possiveis soluções e pergunta qual opção ele quer
	3. Monta o plano de implementação em um arquivo markdown conforme a escolha do usuário e apresenta ao usuário
	4. Espera aprovação ou pedido de alteração do usuário
	
- SolutionImplementation(Recebe plano de implementação)
	1. (Coder) Após aprovação começa a realizar o desenvolvimento conforme os passos do plano de implementação
	2. (Code Reviewer) Após implementação realiza um build para ver se não tem erros de syntaxe
	3. (Tester) Um tester de código se aplicavel
	4. (Documenter) Documentação das alterações
	5. Retorna um arquivo para o usuário de maneira resumida o que foi feito

## SuperAgentes:
(Obs: sempre no primeiro prompt, se eles não tiverem contexto de nada, eles primeiro vão analisar o projeto como um todo, a documentação AGENTS.MD para poder entender melhor o projeto, e posteriormente vão continuar a realizar o fluxo de desenvolvimento proposto)

- Builder: Feito para realizar a implementação de novos recursos e funcionalidades na aplicação
	1. Recebe o Prompt do usuário para compreender o que ele deseja que seja implementado (pergunta ao usuário mais sobre se necessário)
	2. Analisa viabilidade de implementação
	3. PropostSolution()
	4. SolutionImplementation()
	
- ProblemSolver:
	1. ProblemIdentifier(problema)
	2. PropostSolution(markdown com os problemas)
	3. SolutionImplementation(proposta de solução do propost solution)
