# Fluxo de Trabalho
## Agentes

- ProblemIdentifier(problema a ser resolvido)
    1. Recebe o prompt compreendendo qual é o problema que o usuário está reclamando (se necessário pedir mais informações para ter mais detalhes e compreender melhor a dor do usuário)
	2. Identifica o problema no código, pensar quais são os possiveis problemas, confirmando isso no código
	3. após montar as hipoteses, se possivel realizar testes para confirmar as hipoteses com comandos ou execução de testes
	4. com isso decidir os problemas, e montar um arquivo markdown apresentando quais são as possiveis causas do problema

- PropostSolution(Recebe situações para implementações de recursos ou problemas a serem corrigidos)
	1. Monta as melhores soluções para aquele projeto seguindo padrões de projetos e boas práticas
	2. Apresenta para o usuário as possiveis soluções e pergunta qual opção ele quer
	3. Monta o plano de implementação em um arquivo markdown conforme a escolha do usuário e apresenta ao usuário
	4. Espera aprovação ou pedido de alteração do usuário
	
- SolutionImplementation(Recebe plano de implementação)
	1. Após aprovação começa a realizar o desenvolvimento conforme os passos do plano de implementação
	2. Após implementação realiza um build para ver se não tem erros de syntaxe
	3. Um tester de código se aplicavel
	4. Documentação das alterações
	5. Apresentar em um arquivo para o usuário de maneira resumida o que foi feito

Super Agentes:
(Obs: sempre no primeiro prompt, se eles não tiverem contexto de nada, eles primeiro vão analisar o projeto como um todo, a documentação AGENTS.MD para poder entender melhor o projeto, e posteriormente vão continuar a realizar o fluxo de desenvolvimento proposto)

- Builder: Feito para realizar a implementação de novos recursos e funcionalidades na aplicação
	1. Recebe o Prompt do usuário para compreender o que ele deseja que seja implementado (pergunta ao usuário mais sobre se necessário)
	2. Analisa viabilidade de implementação
	3. PropostSolution()
	4. SolutionImplementation()
	
- ProblemSolver:
	1. ProblemIdentifier(problema)
	2. PropostSolution(markdown com os problemas)
	3. SolutionImplementation(proposta de solução do propost solution)
